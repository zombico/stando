    Appearance

    Colors stand for ideas, not places. Change an idea's color and every part of the app that shows it follows.

    Mode
    Colors

    For anything beyond colors (fonts, corner radius, spacing) put CSS in ~/.stando/theme.css. It loads after the app's own styles, so it can override any token, for example :root { --font-sans: "Inter"; --radius-card: 2px; }.

    Runners & models

    The CLIs stando can run, with the models and thinking levels the pickers offer. Any model name the CLI accepts works; type it under Custom. Add or change runners in ~/.stando/runners.json.
